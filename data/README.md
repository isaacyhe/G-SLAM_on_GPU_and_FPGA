# Datasets for G-SLAM

All datasets use the **G-SLAM log format**: each line is either a `ODOMETRY` edge
(robot motion) or a `LANDMARK` observation, with associated information matrix weights.

## Included Datasets

### Synthetic: cityTrees series
Generated by `generate_citytrees.py` — a city-grid environment with robot poses and
landmark observations.

| File | Poses | Notes |
|------|-------|-------|
| `cityTrees100.log.txt` | 100 | Small, for quick correctness tests |
| `cityTrees100_100.log.txt` | 100 | Alternate seed |
| `cityTrees800.txt` | 800 | Primary benchmark (dim=2400) |
| `cityTrees800_gen.txt` | 800 | Generator output, same scale |
| `cityTrees1200.txt` | 1200 | Medium scale |
| `cityTrees1600.txt` | 1600 | Medium-large scale (dim=4800) |
| `cityTrees1k.log.txt` | ~1000 | 1k-pose variant |
| `cityTrees5k.txt` | 5000 | Large scale |
| `cityTrees10k.txt` | 10000 | Large scale (ODOMETRY format) |
| `cityTrees10k.log.txt` | 10000 | Large scale (G-SLAM log format) |
| `cityTrees10k_gen.txt` | 10000 | Generator output |
| `cityTrees20k.txt` | 20000 | Very large (dim=60000) |
| `cityTrees50k.txt` | 50000 | Extra large |
| `cityTrees100k.txt` | 100000 | Maximum scale tested |

### Real-world: Victoria Park
Converted from the SLAM++ dataset (available at
http://sourceforge.net/projects/slam-plus-plus/).

| File | Poses | Landmarks | Notes |
|------|-------|-----------|-------|
| `victoria-park.log.txt` | 7120 | 151 | Full dataset, ~105k observation pairs |
| `victoria-park-100.log.txt` | 100 | ~30 | First 100 poses, for GJ testing |

## Scripts

- **`generate_citytrees.py`** — Generate synthetic cityTrees datasets.
  ```
  python3 generate_citytrees.py <n_poses> <output.txt> [seed=42]
  ```

- **`convert_slampp.py`** — Convert SLAM++ ODOMETRY/LANDMARK format to G-SLAM log format.
  ```
  python3 convert_slampp.py <input.txt> <output.log.txt>
  ```
